# Portfolio - Sara Hereda Style

Proyecto portfolio listo para abrir en servidor local.

## Requisitos

- Node.js 18 o superior

## Como abrirlo

1. Abre terminal en esta carpeta:
   `/Users/saraheredahernando/Documents/Codex/2026-04-24/quiero-crear-un-portfolio`
2. Ejecuta:
   `npm run dev`
3. Abre en el navegador:
   `http://127.0.0.1:4173`

## Cambiar puerto (opcional)

`PORT=8080 npm run dev`

## Archivos principales

- `index.html`
- `styles.css`
- `script.js`
- `server.js`
